## Editorial conclusion

R5's five-group theorem layout is retained; R4's ten
separately named theorem families are restored as
explicit contracts with their quantification and
physical transfer frontiers. In particular the
same section now distinguishes a checked source
instance, a general calculus soundness theorem,
the actual Clojure checker/translator refinement,
the abstract induction theorem, and the separately
qualified real XTDB/browser execution claim.
No developer-maintained second formal application
and no implicit whole-host Clojure theorem are
introduced.

## R4 and previous accepted-part preservation decisions

1. **Certified composition soundness** remains a
   theorem over exact source subject, provider
   guarantee, consumer premise, trusted context,
   substitution and inherited used premises.
   A trusted assumption is not a provider proof.

2. **Rule type safety** covers nominal/domain
   correctness, short-circuit source order,
   optional absence versus present nil,
   explicit error paths and actual declared
   reader footprints. A valid static rule
   is not proof of the current model's
   factual inputs or policy correctness.

3. **Rule-use knowledge** requires the exact
   role/program point, actual source and
   communication, permitted disclosure
   and observation frontier. A global
   branch guard does not make every
   browser participant omniscient.

4. **Provenance safety** forbids promotion
   of client role labels, shape-matched
   basis receipts and copied authoritative
   reports except through admitted
   and appropriately enforced rules.

5. **Authority non-escalation** remains
   a theorem about no protected
   capability being derived from
   untrusted input without trusted
   model/server authorization. Proof
   of the rule alone is not the
   physical guard at the write or
   read boundary.

6. **Projection preservation** separates
   supported global/local trace
   simulation direction, observables,
   hidden steps and role knowledge.
   A lockstep or weak witness for
   one schedule is not universal
   projection proof.

7. **Executable-plan provenance**
   requires a plan actually derived
   from the admitted projection
   and its current semantic
   dependencies. Emitted/served/
   loaded artifacts and installed
   routes need independent
   source/physical binding.

8. **Stale certificate safety**
   checks source-required dependencies
   and typed compatibility at the
   current trusted consumer.
   A valid new Request S18 may
   still make old Claim S17
   evidence unusable, while
   unchanged abstract theorems
   may survive an unrelated
   physical code change.

9. **Progression preservation**
   conservatively composes
   opaque basis obligations,
   refuses arbitrary order
   inferred from SSE arrival
   or client timestamps,
   and discharges requirements
   only with qualified source,
   basis and projection
   coverage. An actual
   provider must establish
   its claimed witness.

10. **Browser semantic adapter
    safety** retains execution
    and resource ownership,
    retirement before physical
    cleanup, effect-time
    permission, real HTMX/OOB
    target completion and
    honest partial installation.
    The shell and adapter
    require distinct
    correspondence evidence.

11. **Small kernel soundness
    is a quantified theorem.**
    For all accepted derivations
    and valuations satisfying
    Gamma, P must hold.
    One truth table/witness
    is exact for its instance,
    not a metatheorem
    or proof that the
    Clojure checker correctly
    implements all inference
    rules.

12. **Typed-proposition bridge**
    keeps application-owned
    atomic predicate semantics
    separate from Boolean
    entailment. Finite
    enumeration has exact
    reader domains/budgets;
    opaque predicates and
    runtime values are not
    silently proved by it.

13. **Guarded transitions
    quantify over genuine
    frames and guards.**
    Simultaneous assignments
    use the same pre-state
    and input, with
    presence/value on
    unwritten fields.
    A pair of Clojure maps
    is not itself a
    qualified XTDB
    transition witness.

14. **Induction is complete
    relative to declared
    original source.**
    Every invariant base and
    every declared operation's
    preservation obligation
    must participate.
    A structurally valid
    pruned DAG or
    caller-selected
    catalog does not
    prove original
    completeness or
    all physical writers.

15. **No vacuous
    HumanHelp success.**
    Initial states must
    be satisfiable
    where the claim
    requires them,
    and eligible Create/
    Claim/Unclaim/Reassign
    and other product
    positives remain
    independent gates.
    A reject-all
    abstract machine
    is not a
    completed product.

16. **Premise and runtime
    capability usage differ.**
    Logical reuse of
    a valid formula
    does not clone
    an execution lease,
    current principal
    permission, actor
    authorization or
    one-Refresh grant.

17. **Safety and liveness
    differ.** A safe
    abstract/portable
    trace with
    unbounded stuttering
    does not guarantee
    progress, especially
    when user Refresh,
    environment
    reachability and
    retention are
    conditional.

18. **Same semantics
    across nodes.**
    Router/failover/
    replay assumptions
    are additional
    physical proof-transfer
    obligations and
    cannot strengthen
    user authority or
    change Claim's
    original meaning.

19. **Evidence honesty
    and independent
    mutations.**
    Copies of reports,
    unsupported proof
    tags, manipulated
    dependency graphs,
    unobserved effects
    and stale assets
    must not pass as
    established
    stronger theorems.
    Paired valid
    controls are
    required.

20. **Theorem ownership
    is not implementation
    completion.** The
    normative family
    defines what
    must eventually
    be proved or
    qualified, including
    original source,
    checker metatheory,
    actual instance,
    model writer and
    installed browser.
    The review makes
    no claim the
    current implementation
    discharges them all.

  It explicitly distinguishes a
  checked report from a theorem
