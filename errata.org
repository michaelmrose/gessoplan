* Purpose

This is the numbered log of corrections, clarifications, and other editorial
amendments identified while reviewing the Gessoplan canonical design. It is
maintained separately from the normative specification; an entry here does not
itself change a requirement. An accepted change is made in its owning Org
source section and linked here.

Number entries consecutively, retain their numbers as permanent review
references, and record proposed items as =Pending= until applied. Each entry
should identify the issue, the edited (or proposed) source location, the
resolution, and the implementing commit where available. Links below are
relative to this repository root and target headings in the actual Org source
files, not generated output or historical copies.

* Numbered errata

1. *Semantic-category construction in design priority and dependency direction*
   - *Status:* Applied — 2026-11-14
   - *Edited section:* [[file:src/01/01.02-full-language-and-dependency.org::*Design priority and dependency direction][Part I: Design priority and dependency direction]]
   - *Related normative detail:* [[file:src/02/02.01-values-and-evolving-values.org::*Representation, semantic category, and admission][Part II: Representation, semantic category, and admission]]
   - *Issue:* Two maps with the same keywords or Malli shape, or identifiers
     with the same UUID representation, can have incompatible semantic
     categories. The early dependency overview did not make Gesso's obligation
     to preserve these distinctions prominent enough.
   - *Resolution:* State explicitly that checked construction or admission
     establishes and preserves semantic categories; require the earliest
     supported consuming boundary to reject incompatible or unadmitted values
     with an informative diagnostic. Keep nominal representation, provenance,
     runtime authority, and proof distinct, without imposing routine manual
     wrappers on application authors.
   - *Commit:* [[https://github.com/michaelmrose/gessoplan/commit/b2ce497828b7d5fb779d0592802d689569dd19ec][b2ce497 — Clarify semantic category construction]]
