## Editorial decision

The preferred R5 order is a genuine improvement: the permanent semantic
vocabulary and typed rule judgments can be constructed before the full
proof kernel is completed. Unlike R4's chronology, these are semantic
building blocks; they do not replace the mandatory Biff lifecycle and
real authoritative model foundation. The earlier physical substrate
requirement is preserved in 12.01 and later host/operations stages, not
silently deleted by changing the label “Stage 1.”

The crucial strengthened join is between an *original public policy*
and a versioned, checked semantic subject. Correctly shaped data,
a matching hash or a typed expression proves neither business
intent nor physical actor authority. Original requirements, the
source's actual dependencies, conditional premises, implementation,
evidence issuer and installed execution remain separately identified.
A completed smaller registry cannot redefine the full HumanHelp
product denominator.

Stage 2 remains the *first closed certifiable fragment* inside
ordinary Clojure/ClojureScript authoring. It does not mandate a new
application-only rule language, waive opaque callbacks, or treat a
closed grammar as proof of every richer R4 field/relationship
construct. Syntax, intrinsic type, concrete evaluation and use
in a knowledge-bearing/authoritative context have different
judgments with distinct evidence.

## Actual Gesso v1622 correspondence

The local Gesso repository was inspected at commit
`1b5e10e71c00e7784b019dee7dc1198a96fd03f6`.
These names are *actual source files*, not inferred future APIs:

- `src/gesso/model/core.clj`: Malli-backed model descriptors,
  Graph projection and ordinary single-document operation derivation;
  complex model Graph/FX remains application-owned. This is not the
  entire production HumanHelp Claim/writer inventory.
- `src/gesso/assurance/subject.clj`: canonical structural subject
  fingerprint, expressly not semantic equivalence or executable proof.
- `src/gesso/assurance/claim.clj`: closed *unadmitted* evidence claim
  descriptions, scope and dependencies, not discharged proof.
- `src/gesso/assurance/admission.clj`: restricted in-process structural
  handles, not production authorization or checker soundness.
- `src/gesso/assurance/rule.clj`: closed validated syntax, declared
  reader footprint and resource bounds, not type or evaluation.
- `src/gesso/assurance/rule_type.clj`: nominal enum, optional/nullable,
  path-sensitive intrinsic type checking, not permission to read or commit.
- `src/gesso/assurance/rule_eval.clj`: one supplied binding, exact
  presence, strict Boolean and ordered short circuit; no provenance,
  general theorem or installed runtime gate follows.
- `src/gesso/assurance/rule_normalize.clj`: original syntax/type
  rechecks and conservative fingerprint identity preserving order;
  unchanged hash does not qualify changed physical implementation.
- `src/gesso/assurance/opaque.clj`: unadmitted Clojure/external service
  descriptions; declared purity, termination and outputs are not
  confinement, external provenance or guaranteed actual effects.
- `src/gesso/assurance/proof/typed_value_semantics.clj`: independent
  bounded partial-map value semantics for missing/nil/false, not
  universal JVM/CLJS/XTDB correspondence.
- `src/gesso/assurance/diagnostic.clj`: first-blocker source-relative
  explanation, explicitly diagnostic rather than admission.

The matching rule, rule-type, evaluator, normalizer, opaque and typed
presence test files were inspected for existence only. No JVM/Node,
Chromium, XTDB, formal prover or multi-node tests were executed in
this editorial revision. Source correspondence does not establish
general proof soundness, the effective running Biff writer or
production HumanHelp acceptance.

## Paired positive and adversarial design oracles

| Eligible positive | Nearby counterexample | Earliest required owner |
| --- | --- | --- |
| A genuinely model-owned Claim rule is reused by Choreo and operation | Same-shaped rule for a different actor/Request/Organization substitutes | Source/semantic subject and trusted model identity |
| Original product inventory includes all required actions | Generated successful smaller graph silently omits Response/Reassign | Independent capability denominator and application assembly |
| Optional nullable score guard precedes comparison | Comparison executes before presence or non-nil proof | Closed type/path judgment, not general Boolean false |
| One immutable typed binding evaluates with declared enum and presence | Wrong enum, absent read, present nil or false is coerced into other state | Type/reader binding validator and evaluator |
| `:and`, `:or`, `:implies` preserve evaluator's ordered paths | Reordering produces absent read or different failure/first blocker | Normalization/interpretation checker |
| Valid original Clojure source elaborates to bound closed rule | Copied manually written AST with same example result is credited as original | Source elaboration and correspondence gate |
| Opaque Organization predicate remains usable under scoped premise | Output map or asserted purity is treated as proven hidden-effect absence | Opaque contract and physical enforcement |
| Nominal enum correctly distinguishes two domains | Same keyword spelling from unrelated enum is silently accepted | Closed nominal typing |
| Full Claim checks current Membership and one-primary RequestAssignment | A typed status conjunct on stale synthetic data grants transaction commit | Actual model guard and physical writer |
| Unrelated abstract proof is reusable under stable dependencies | Changed XTDB adapter/backend/browser inherits old physical qualification | Dependency and release/physical-correspondence gate |
| Finite typed-rule claim reports its exact bounds | Abstract finite pass treated as general proof/installed authority | Proof kernel/issuer and S0–S4 transfer |

These cases are future acceptance obligations, not passing test
results. No proof assistant or mandatory Rust router is imposed
on application authors.
