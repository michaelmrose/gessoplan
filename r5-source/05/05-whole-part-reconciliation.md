## Outstanding obligations — not silently discarded

- **Browser continuity gap:** the current inspected v1622
  `release-height-lock!` uses CSS-value equality; a newer
  owner writing the same value cannot be distinguished solely
  by that check (05.05 audit). Normative owner-based cleanup
  remains a future implementation/conformance obligation.
- **Physical effects:** multi-target partial/indeterminate
  installation, admitted DOM completion, delayed callbacks,
  reentrant host effects, protected post-capture edits and
  diagnostic observer isolation need appropriate actual
  host and deployment witnesses.
- **Backend:** complete RequestAssignment transaction
  correspondence, qualified XTDB basis/coverage, command
  idempotency/readback, history retention and non-HTTP
  writers require trusted provider and writer evidence.
- **Artifact/proof:** a per-role plan digest or matching
  sidecar is not a global theorem, a verified opaque
  implementation, a portable canonical codec or the actual
  JavaScript bytes served by every deployed entrypoint.
- **Behavioral product:** real eligible HumanHelp Create,
  Claim/retry, lifecycle, manager-directed Reassign,
  one-Refresh remote-R/local-S, proper local search and
  continuity, honest recovery, and a separately selected
  response-flow contract still need independent positive
  witnesses; a reject-all or empty-board test is vacuous.
- **Liveness and scope:** retention, availability, fairness,
  user action, backend and resource-budget assumptions
  remain explicit; a finite witness is not unconditional
  universal convergence or arbitrary host-code safety.
- **Dynamic assembly:** checked Hiccup snapshots and the
  canonical wrapped serving path do not establish coverage
  of unexamined dynamic branches, pre-serialized HTML,
  alternate startup or a later replaced route/asset.

These are implementation, correspondence, evidence or
independent product obligations, not reasons to delete
timeless intended-design requirements.
