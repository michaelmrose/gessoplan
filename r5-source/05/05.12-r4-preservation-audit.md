## Preserved R4 obligations

- Production and proof-enabled testing execute one canonical
  `ExecutablePlan`. The `DiagnosticProofSidecar` is a sibling
  compiler/checker product, not a proof-enriched alternate machine,
  a semantic input or a model authorization token.
- Explanations require exact plan identity. Similar state counts,
  source names, timestamp, compatible plan version or copied digest
  are not independently sufficient proof or trusted correspondence.
- R4 distinguishes runtime locator, semantic source identity,
  proof-obligation identity and executable content digest.
  The selected transition must be observed from the true step,
  not reconstructed from potentially divergent callbacks.
- The production semantic trace must remain the same with an
  absent, present or corrupted optional sidecar, for equal
  admitted initial state and normalized event sequence,
  modulo diagnostic-only outputs.
- This is a conditional semantic noninterference claim,
  not wall-clock/browser scheduling equivalence with an
  arbitrarily slow or malicious same-process observer.
- Required audit/compliance operations cannot be hidden in
  a best-effort diagnostic output path and then waived.
- Sidecars do not establish principal permission, authorized
  observations, command outcomes or physically installed DOM.

## Focused R5.1 improvements

1. **Total compiler mapping:** preserve all actual synthetic,
   direct and merged receive alternatives/semantic origins,
   not a guessed unique source for a compact locator.
2. **Proof-status taxonomy:** artifact matching is distinct
   from structural proof, verified global terminal meaning,
   a valid or failed *concrete witness*, all-schedules proof,
   asserted opaque implementation, and physical/installed
   browser evidence. A bound witness may still fail.
3. **Exact global subject:** role-plan equality cannot replace
   source-relative proof/terminal identity. Checker claim
   provenance includes issued result, premises, dependencies
   and accepted checking mechanism.
4. **No self-verified sidecar:** `:valid? true= and a claimed
   checker label do not authenticate a derivation; required
   build/assembly checking cannot be made optional by omitting
   runtime diagnostic metadata.
5. **True selected-transition trace:** an event excluded before
   selection has no fabricated successful locator; later
   physical failure remains a distinct correlated outcome.
6. **Privacy and immutability:** observers receive bounded,
   redacted immutable projections rather than live authority
   handles or mutable owner registries.
7. **Fixed-input semantic noninterference:** equality explicitly
   preserves ordered required abstract effects, state,
   classifications, owner identity and unresolved obligations.
   Real-world scheduling/liveness requires additional premises.
8. **Containment and audit:** a blocking observer is not
   contained by catching exceptions; choose isolation or an
   explicit nonblocking premise. Lossy queues drop optional
   diagnostics only; required audit is a semantic effect.
9. **Paired positive/adverse histories:** compacted mappings,
   source-divergent proofs and bound failures, mismatched
   sidecars, malicious/blocked observers, and lost audit work.

## Current Gesso implementation inspected

Gesso `application-assurance` at
`1b5e10e71c00e7784b019dee7dc1198a96fd03f6` (v1622):

- `src/gesso/choreo/project.cljc` preserves compiler-only
  runtime origins, semantic continuations and locations,
  including synthetic/collapsed states. This information
  is not an executable runtime branch authority.
- `src/gesso/choreo/artifact.clj` emits sibling role-keyed
  plans and sidecar, binds exact per-role digests and the
  current structural proof version, and rederives concrete
  lockstep/weak witnesses and their true results against
  the exact current global choreography.
- `test/gesso/choreo/artifact_test.clj` includes
  `corrupt-or-mismatched-sidecar-is-rejected-without-changing-the-plan`
  and
  `identical-executable-plans-cannot-hide-different-global-terminal-semantics`,
  as well as bound concrete witness tests.
- `src/gesso/live/browser/adapter.cljc` separates
  `:diagnostic/ignored` from required semantic effects
  and exposes `semantic-effects` to filter diagnostic
  outputs in pure transitions.

These mechanisms support specific structural/checker and
pure-adapter claims. They do **not** establish full optional
observer isolation, all sensitive-data redaction, real
Chromium host noninterference, universal proof, or the
deployed browser asset's physical correspondence.

**No Gesso code was modified. No JVM, Node, Chromium,
XTDB, Python assembly, or formal proof tests were run**
during this documentation revision.
