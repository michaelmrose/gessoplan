## Current implementation correspondence and nonclaims

- `src/gesso/assurance/proof/certificate.clj` issues limited genuine JVM-local proof handles for its selected kinds and rechecks the original source and live declared dependency graph. The source explicitly rejects copied reports, signed-looking bytes and arbitrary actual XTDB/browser execution as certificates.
- `src/gesso/assurance/dependency.clj` admits exact declared graph identities through JVM-local registered handles. It cannot prove complete deployed writer/handler coverage or executable implementation correspondence.
- `src/gesso/assurance/admission.clj` distinguishes issuer-bound structural handles from manually created objects or EDN maps, without treating structural identity as a theorem.
- `src/gesso/assurance/subject.clj` computes canonical versioned bounded structural EDN identity, not arbitrary Clojure denotational equivalence.
- `src/gesso/live/browser/build.clj` supports exact selected manifest, emitted JS bytes and build receipt correspondence, but cannot by itself prove the deployed browser's runtime effects or a live authorization.
- `src/gesso/assurance/proof/application_assurance_report.clj` is a source-derived conditional non-authoritative summary; its permanent open physical writer, proof metatheory, implementation and deployed browser obligations remain.

These useful mechanisms do not establish an existing secure serialized proof cache, durable externally authenticated check/test receipt, current full installed-host release approval or a general A44-to-B45 physical correspondence theorem.
