## Independent R4/R5 disposition

R4 explicitly requires the actual kernel/dedicated checker identity and version, TCB classification, distinct real tested and served artifact identities, proof assumptions, incomplete gate evidence and independent user-capability acceptance. R5 is more precise about immutable release intent, canonical original obligations, candidate/installation/activation decisions, scope and exclusions; neither the R4 list nor R5's eight bullets should be lost. The revision adds a typed claim/evidence graph and a field-by-field crosswalk of source, theorem, concrete implementation, browser artifacts, actual provider, gate observation, release phase and HumanHelp milestone. It intentionally keeps the root report explanatory, not issued authority or a second application's source registry.

## Current Gesso v1622 correspondence and limitations

- `src/gesso/assurance/report.clj` creates a source-bound report for one proof-linked operation by rechecking original executor/certificate/obligation materials. It explicitly does not authenticate caller-reported test execution, arbitrary Clojure correctness, installed server routes, proof-kernel soundness, physical XTDB refinement, browser effects or production admission.
- `src/gesso/assurance/proof/application_assurance_report.clj` recomputes conditional source closure, composition/provenance and observed writer records from original sources, but reports permanent open independent kernel, deployed adoption, real writer-completeness, physical transition refinement and browser/HTMX/SSE gaps.
- `src/gesso/assurance/proof/certificate.clj` issues scoped JVM-local checked proofs with exact premises. Its source expressly does not treat an abstract conditional proof as a current runtime or all-writers theorem.
- `src/gesso/live/application_preflight/assurance.clj` describes current selected HTML/rendered-surface preflight and its physical limitations; no actual whole-release report can infer live installed handler and all serving paths from the explanatory map alone.
- `src/gesso/live/application_preflight/authoritative_coverage.clj` checks a host-provided entry-point enumeration but cannot prove that enumerator complete or that any hidden XTDB writer is absent. Such gaps remain named in a root report.
- `src/gesso/live/browser/build.clj` binds exact generated JS bytes, selected manifest and an artifact receipt under the supported build path. This does not prove the production server serves that file or the user browser completed an authorized DOM effect.

These are real relevant components, not an existing independently authenticated multi-phase release root, full original source/product catalog, universal checker metatheory, complete physical XTDB writer closure, current production host activation or completed HumanHelp milestone. This audit claims editorial design correspondence only.
