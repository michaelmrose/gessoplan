## Reconciliation decision

Keep R5's eleven-row source theorem/production-obligation
division; R4's rich enumerated tests and implementation
details make those targets falsifiable. For each claim
family explicitly retain: its original source domain,
semantic judgment/quantifier, actual host transfer,
environment/provider premises, independent evidence
method and positive/adversarial scenario. A source
certificate, static plan and matching status map must
not be mistaken for the corresponding installed
and physically enforced proof.

This section states *targets*, deferring theorem
mechanics to 10.03–10.12, trust/failure realization
to 10.13–10.15 and deployment routing/failover
to 10.16–10.19. It does not create a second
application rule language.

## R4 preservation decisions

1. **All eleven R4 categories survive.** The
   matrix retains choreography, role knowledge,
   typed rules, authoritative model, progression,
   optimism, browser adapter, portability,
   whole-application closure, browser/server
   authority and conditional progress.
2. **Semantic/physical edges stay separate.**
   Every row names the abstract relation and
   actual host/transaction/browser mechanism.
   Matching names, digests or returned records
   cannot replace actual execution evidence.
3. **Projection is trace-indexed.** Roles
   require the proper branch-producing
   knowledge, permitted hidden steps and
   real communicated occurrence. One good
   lockstep/weak witness is not universal
   global/local trace refinement.
4. **Knowledge is provenance- and privacy-aware.**
   Sender/receiver may know only justified
   values; different authorized projections
   can legitimately differ without breaking
   shared-scope agreement.
5. **Nominal/presence and reader semantics.**
   R4's optional, present-nil, short-circuit,
   source reader footprints and closed-variant
   checks remain independent of runtime
   schema shape or model-policy truth.
6. **Portable integers are explicit.**
   A JVM exact integer beyond a JS
   Number's safe range is not transported
   by rounding. JVM, Node and Chromium
   need a selected actual supported
   codec/operator contract and separate
   real-execution evidence.
7. **Atomic model guard is physical.**
   Public Request/RequestAssignment and
   actual current Membership/Organization
   eligibility must be bound to the
   transaction's atomic mechanism; a
   pre-read or schema-valid transaction
   is not a protected incorporation proof.
8. **Stable command and outcome identity.**
   C42's historical result differs from
   H1/H2 attempts and current Request
   snapshot. Four backend outcomes and
   separate presentation statuses retain
   the correct unknown/reconciliation path.
9. **Progression algebra is conservative.**
   An opaque basis requirement cannot
   be weakened by keeping the latest
   arriving SSE or larger-looking token.
   Only appropriately qualified witness
   and exact authorized read coverage
   may discharge a requirement.
10. **No implicit authoritative optimism.**
    A provisional projection never
    grants actor privileges, erases
    remote advisory debt or proves
    its own command incorporated
    merely because a newer current
    state superseded its view.
11. **Browser resource safety at real mutation.**
    Reused DOM IDs do not revive
    retired owners; cancellation is
    best effort, and deferred
    physical mutation checks rights
    again at the actual effect point.
12. **Fragment coordination bounds
    are multi-dimensional.** Logical
    active/queued limits differ
    from retired physical requests
    and retained metadata bounds.
    Shared subscriptions use their
    declared owner-relative event
    path, not an invented command.
13. **Partial OOB effects are not atomic.**
    A successful callback/HTTP 200
    does not establish all DOM
    targets installed. Actual
    completion, target identities
    and explicit partial repair
    remain necessary.
14. **Same plan versus compiled artifact.**
    ExecutablePlan semantics, exact
    build bytes, source manifest,
    installed server assets and
    browser-loaded runtime are
    separate identities/evidence.
    A correct stamp does not
    prove actual emitted JS
    embeds the plan or ran it.
15. **Proof sidecars are noninterfering.**
    Optional diagnostics may affect
    an admission policy but cannot
    change the semantics of an
    already admitted runtime plan.
    Exact artifact identity matters
    to sidecar lookup and reuse.
16. **Three independent closure gates.**
    Declared path closure,
    independent promised product
    capability inventory and
    real dynamic installed host/
    rendered output enforcement
    cannot be collapsed. Missing
    Unclaim/Reassign fails
    positive product acceptance.
17. **Dynamic checks need recovery.**
    Static preflight need not
    predict future Membership;
    it must require a real
    authorization/failure/unknown
    recovery branch before
    operation issuance.
18. **Browser never authenticates
    its own privileges.** Browser
    claims/roles, command IDs,
    observation coordinates and
    metadata are proposals.
    Protected writes and
    reads are granted by
    actual trusted server
    and public model policy.
19. **Conditional progress remains
    conditional.** Fairness,
    provider reachability,
    retention, user action
    and quiescence are
    explicit, not inferred
    from the existence
    of retry, timer,
    route or terminal
    path.
20. **HumanHelp selective adoption.**
    Creator-local Create
    and remote SSE advisory
    remain distinct.
    Viewer remote
    Refresh is one
    explicitly permitted
    acquisition, never
    an automatic pull
    caused by subscription
    or reconnection.
21. **Multi-node semantics are
    unchanged.** Placement,
    durable routing,
    registration frontier,
    duplicate/lost
    invalidation and
    failover are additional
    production obligations,
    not a second
    operation/authority
    meaning.
22. **Evidence class honesty.**
    A finite model, tested
    browser scenario,
    established source
    judgment and
    qualified physical
    observation remain
    separately scoped.
    Counterexample,
    unsupported,
    unobserved and
    timed-out work
    are not synonyms.

## Gesso v1622 implementation correspondence and limits

- `src/gesso/choreo/correspondence.cljc`
  independently replays one specified
  global/projected realization
  schedule with lockstep/weak
  witness classifications. Its
  commentary distinguishes
  distributed observation
  alphabets and physical
  transport delivery; it
  does not establish
  all-schedules semantic
  projection theorem or
  deployed browser provenance.
- `src/gesso/live/browser/refinement_correspondence.cljc`
  compares a browser adapter
  trace with one independently
  replayed Choreo schedule.
  The source explicitly leaves
  actual network message origin,
  browser machine/instance
  identity, physical host,
  XTDB incorporation
  and universal trace
  refinement open.
- `src/gesso/live/progression.cljc`
  treats bases as opaque and
  merges refresh requirements
  conservatively. Its
  =:advances= witness
  shape is not proof the
  declared progression
  actually occurred;
  a trusted provider
  must establish truth.
- `src/gesso/assurance/proof/typed_portability_correspondence.clj`
  supplies a source-bound JVM
  portable witness and refuses
  integer values outside JS
  safe Number bounds; it
  explicitly does not
  establish that CLJS/
  Node executed or that
  browser results agree.
- `src/gesso/live/browser/shell.cljs`
  is an imperative host shell
  interpreting pure adapter
  effects and owning timers,
  transports and continuity
  resources. Declared
  nonsemantics of physical
  objects is a meaningful
  design boundary, but
  source inspection alone
  does not prove all
  physical late-callback/
  DOM/HTMX scheduling
  traces safe.
- `src/gesso/live/browser/build.clj`
  derives exact manifest/
  bootstrap/compiled-byte
  receipts and verifies
  output before publication.
  Its documentation
  explicitly distinguishes
  mere stamp agreement
  from actual compiled
  implementation of a
  semantic manifest and
  from real browser loading.
- `src/gesso/live/application_preflight/rendered_surface.clj`
  inspects supplied Hiccup
  surfaces and request
  coordinates. It disclaims
  proving every possible
  render state, streaming
  or deferred path.
- `src/gesso/live/application_preflight/inductive_contract.clj`
  joins a declared abstract
  induction catalog with
  current source-issued
  handler/route products,
  but explicitly leaves
  actual host adoption,
  direct/initializer
  physical writers,
  protected transaction
  correspondence and
  checker soundness open.
- `src/gesso/assurance/proof/physical_writer_inventory.clj`
  asks a host enumerator
  for known effect-capable
  XTDB paths; the module
  states that a matching
  list is *not* proof of
  completeness, no hidden
  bypass or actual
  physical enforcement.
- `src/gesso/assurance/proof/transaction_outcome_progression_correspondence.clj`
  classifies one selected
  physical outcome/
  command-resolution/
  progression report,
  while preserving
  independent source/
  authorization/
  provenance/commit
  and broader physical
  refinement obligations.

These real precursors
support part of the
intended architecture.
No complete HumanHelp
product proof, universal
distributed
correspondence theorem,
all-physical-writer
inventory, actual loaded
Chrome bundle proof,
independent external
proof-kernel
meta-soundness or
overall app
certificate is claimed.
Source names and
reported success
fields are not
independent runtime
test results.
