## Preservation of R4 requirements

1. **Semantic identity is not silently erased.** A missing plan,
   observation basis, transport, executor or acquisition binding may
   cause unavailability, blocked rendering, or explicit construction
   failure. It never licenses deletion of :choreo/op followed by an
   ordinary anonymous POST to the same protected semantic route.
   Independently declared alternate realizations remain legitimate.
2. **Ordinary HTMX remains ordinary.** Search, navigation, filters and
   separately authorized non-Choreo actions are permitted. Anonymous
   requests to a protected semantic route cannot escape its semantic
   protocol solely by dropping metadata. Ordinary state-changing routes
   still participate in the applicable effect/writer coverage argument.
3. **Check effective physical action.** R4 explicitly mentioned
   parameterized method/route matching, native forms, inherited HTMX
   attributes, submitter overrides and indirect component helpers.
   Section 07.05 now restores those near misses and requires transport
   suppression for genuinely unavailable semantic controls.
4. **Exact route selection and operation agreement.** Method, decoded
   path Request, query/envelope selectors, precedence, protocol,
   supported normalization and installed dispatch agree. An R1/R2
   request mismatch is a pre-effect error; direct clients are not
   trusted merely because the rendered page once passed.
5. **Actual installed executor and public model delegation.** R4's
   trusted server operation registry must derive semantic meaning
   from the model and Choreo. The trusted route handles decoding,
   authentication, FX context and outcome protocol; it does not own a
   second Request/RequestAssignment business rule implementation.
   Same-named arbitrary functions do not establish delegation.
6. **Real physical route/binding evidence.** A declared handler,
   issued/constructed dispatcher, Biff system handler slot, server
   captured handler and observed effect are different subjects.
   Host adoption and later middleware/Var replacement must not be
   inferred from a stale source-relative success report.
7. **Capability supply is typed and scoped.** R4 required actual
   provider origin, invocation/lifetime, shape and failure contract.
   The concrete :biff.fx/now value consumed by Claim must actually
   be bound, not merely named :clock. A transaction capability is
   not model authorization. Structurally admitted providers may
   still fail at runtime and need declared recovery.
8. **Command and result distinctions survive transport.** Stable
   logical :gesso/command-id, attempt/request identity, permitted
   retries, historical incorporation, current state and physical
   adoption answer different questions. Unknown delivery cannot
   silently become rejection or a fresh logical command.
9. **Browser metadata cannot grant server trust.** Principal,
   membership, tenant/organization authorization, authority roles,
   assembly stamps and purported certificates cannot come from
   untrusted client declarations. Origin/request-integrity defenses
   remain part of an applicable cookie-auth transport profile.
10. **Positive real paths and adverse controls.** Fourteen cases
    require successful eligible Claim plus controlled failures for
    anonymous semantic requests, effective form actions, method/path
    collision, wrong Request target, route precedence, changed
    handler, missing operation discriminator, forged principal,
    wrong clock shape, lost-response retry, stale worker,
    post-effect observer and ordinary HTMX read.

The longer R4 illustrative registry maps and transport diagrams are
preserved as behavioral and falsification obligations, not converted
into speculative current Gesso public APIs. The R5 organization,
smaller conceptual contracts and explicit distinction between
assembly, runtime and proof remain preferred.

## Gesso source correspondence and nonclaims

- src/gesso/live/application_preflight/rendered_request.clj and
  rendered_surface.clj implement inspection of Hiccup physical request
  coordinates and canonical semantic affordances. The real test
  test/gesso/live/application_preflight/semantic_route_test.clj includes
  rejection of anonymous parameterized semantic POST, the allowed
  ordinary HTMX case and method-sensitive route collision. This is
  structured/supported Hiccup coverage, not proof against arbitrary
  post-render JavaScript or unwrapped raw HTML.
- src/gesso/live/application_preflight/operation_summary.clj derives
  declared route method/path/transport correspondence for the current
  OperationAcquisitionAssembly; it does not install the production
  router or certify arbitrary server callback effects.
- src/gesso/live/application_preflight/certified_contract.clj contains
  issued Ring handlers that invoke exact certified-plan executors.
  It explicitly leaves request->input! conversion, response callback,
  actual deployed router capture, current authorization, model
  policy, XTDB physical execution and external writer coverage as
  separately owned premises.
- src/gesso/assurance/proof/checked_biff_host_adoption.clj checks an
  opt-in local Biff handler slot against a source-issued router; it
  does not independently authenticate that a network server consumed
  the returned Biff system.
- src/gesso/assurance/proof/xtdb_gateway_route_target_provenance.clj
  implements a deliberately *narrow* literal-route, fixed-target
  source-registered resolver, including an opt-in plan-target-bound
  variant. It explicitly excludes parameterized arbitrary routing,
  independent business truth for the target declaration and universal
  real XTDB request/transaction causality. This must not become a
  universal route language restriction in the finished Gesso design.
- src/gesso/assurance/proof/xtdb_gateway_biff_request_mediation.clj
  offers opt-in checked Biff request mediation with one-use writers.
  Its bounded-fair mode serializes concurrent dispatch behind one
  lease; it does not implement parallel writer execution or prove
  actual deployed HTTP server adoption. The finished ordinary
  application concurrency contract is stronger.
- src/gesso/assurance/proof/installed_route_guarded_correspondence.clj
  classifies joined local route/guarded-plan evidence and explicitly
  leaves plan-to-executor binding, authenticated physical transaction,
  complete physical write coverage and universal refinement open.

Current test existence and source-level behavior are not proof of a
fresh suite pass or the finished routing/production guarantee. No
Gesso JVM, XTDB, Chromium or formal tests were newly run for this
editorial revision.

## Cross-part joins and outstanding obligations

Part II owns actor/principal/source/authorization and evidence
vocabulary. Part III owns the admitted global Choreo operation, not
HTTP method strings. Part IV owns guarded Request/RequestAssignment
atomic transitions, command continuity and authoritative readback.
Parts V–VI own real browser realization, physical effect/adoption
and resource retirement. Part VII's earlier 07.01–07.04 sections own
whole-application assembly and effect coverage; 07.06–07.15 must
establish exact browser asset, rendered output, acquisition,
deployment enforcement, semantic audit and independent acceptance
without silently substituting test-built or metadata-only paths.
Part VIII still requires real eligible Create, Claim, manager
Reassign and remote advisory/one-Refresh behavior. Parts IX–XII
retain stronger checker/refinement, multi-node and release duties.
